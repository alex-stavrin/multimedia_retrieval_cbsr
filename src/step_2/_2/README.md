# database_analyzer.py

```database_analyzer.py``` loads the shape analysis CSV produced by ```shapes_analyzer.py```, plots the distribution histogram (and mean/median) for a chosen property column, and detects outliers using both the Interquartile Range (IQR) and percentile methods.

You can run it from the root directory with:  
```python -m src.step_2._2.database_analyzer -i ./analysis_output/output.csv -p n_points -b 20 -s -o ./analysis_output/n_points_histogram.pdf```  
-i / --input = Path to the input CSV file generated by Step 2.1.  
-p / --property = Name of the CSV column to analyze (for example `n_points`, `n_faces`, `shape_class`, `face_type`).  
-b / --bins = Number of histogram bins for numeric columns (default is 20).  
-s / --save = If present, saves the generated plot to a file instead of displaying it interactively.  
--export = If present, exports the detected outlier rows sorted by the analyzed property to the CSV path given by `-o`.  
-o / --output = Output file path for the saved plot or the exported outliers CSV.
