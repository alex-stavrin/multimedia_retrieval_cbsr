# repairment
## Repaire Wirefram
The python file for this is ```repair_wireframe.py```

Tries to repair the given database root, fixing holes, cleaning meshes, and rewinding faces to fix the normalisation.

### How to run
You run it from project root directory. Examples:

```python -m src.step_2._repairment.repair_wireframe -i ./3d_models/ -o ./3d_models_repaired/```

The -i/--input flag signifies the input root directory, the -o/--output flag signifies the output root directory. The -s flag is optional, one can specify the exact steps it should take within the repairment if needed.

## Repair Analyzer

The Python file for this is `repair_analyzer.py`. It compares mesh statistics before and after hole filling, saving the results to a CSV file.

### How to run
Run it from the project root directory. To compare two databases, use `python -m src.step_2._repairment.repair_analyzer -b ./3d_models/ -a ./3d_models_repaired/ --csv_path ./repair_statistics.csv`. The `-b`/`--before` and `-a`/`--after` flags specify the original and repaired database directories, while `--csv_path` specifies where the comparison results are saved.

To plot properties from an existing CSV, use `python -m src.step_2._repairment.repair_analyzer -b closed_raw -a closed_after --csv_path ./repair_statistics.csv --plot`. Here, `-b` and `-a` specify the CSV column names to compare. The optional `--figure` flag specifies a path to save the plot instead of displaying it.

## Repair Statistics

The Python file for this is `plot_closure_statistics.py`. It analyzes mesh closure statistics from a repair report CSV, categorizing meshes as already closed before repair, closed by repair, or still open after repair. It prints the counts and percentages and saves a plot.

### How to run
Run it from the project root directory using `python -m src.step_2._repairment.plot_closure_statistics --csv_path ./repair_statistics.csv`. The `--csv_path` argument specifies the input CSV file. The CSV file is generated by repair_wireframe, not a shape analysis CSV file. By default, the plot is saved alongside the CSV with `_closure_statistics` appended to the filename and a `.png` extension.

To specify a different output path, use `--output ./plots/closure_statistics.pdf`. Add `--show` to display the plot interactively; otherwise, the plot is closed after saving.
