# DR (Dimensionality Reduction)

## tsne_engine.py
This file reduces the feature vectors of all shapes to 2D with t-SNE (scikit-learn) and saves the points, so the scatterplot does not have to run t-SNE again. It uses the same csv files and the same columns as the KD-tree of `src/step_5/ANN`. The output has one row per shape with the columns `file_path`, `shape_class`, `x` and `y`. You can run it:
```python -m src.step_5.DR.tsne_engine --elementary_csv {path_to_elementary_desciptors_csv} --histogram_csv {path_to_histogram_descriptors_csv} -o {name_of_output_file}```

The default output is `analysis_output/embeddings/tsne.csv`, and the points can be read again with `load_embedding()`.

By default (`--distance step4`) t-SNE uses the distance of the Step 4 search (the weighted Euclidean distance of the elementary descriptors and the weighted EMD of the histograms) instead of the Euclidean distance between the feature vectors. For this the distances between all pairs of shapes are calculated with the `ShapeDistanceCalculator` and given to t-SNE as a matrix, which takes about 35 seconds for 2 483 shapes. It needs the weights file (`--weights_csv`), and the elementary and histogram csv files should be the same as the ones of the weights. With `--distance euclidean` the Euclidean distance between the feature vectors is used instead (and no weights file is needed). In code, a matrix of distances can be given to `reduce(distances=...)`, for example the one from `step4_distances(calculator)`. The points of `analysis_output/embeddings/tsne.csv` were made with:
```python -m src.step_5.DR.tsne_engine --elementary_csv analysis_output/descriptors/simple_descriptors_normalized.csv --histogram_csv analysis_output/descriptors/histogram_new_sampling_descriptors.csv --weights_csv analysis_output/distances/weights_emd_hist_sampling_descriptors.csv```

The options are `--perplexity` (default 30) and `--seed` (default 0, so the result is the same every run). The Euclidean distance on the raw vectors is mostly decided by the groups with the largest values (6 scalars against 320 histogram bins), so by default every group of columns (the scalars together, and each of the five histograms) is first scaled to a total variance of 1. With `--no_balance` the vectors are used as they are.

At the end the program prints how many of the 10 nearest neighbours of a shape have the same class, in the feature space and in the 2D plot. With the new histogram descriptors (`histogram_new_sampling_descriptors.csv`) and perplexity 30 this is 0.333 in the feature space and 0.303 in the plot, and with the Step 4 distance 0.342 before the reduction and 0.305 in the plot. (With the old histogram file the numbers were 0.260 and 0.232, and 0.213 in the plot without the balancing.) Perplexity 5 to 100 gave values between 0.215 and 0.241, and the trustworthiness of the plot (10 neighbours) was highest at perplexity 30, with 0.956.

## scatterplot.py
This file shows the points of `tsne_engine.py` in a light-mode scatterplot, coloured by class (the same colours as in the Step 4 interface) with a scrollable legend on the right showing which colour corresponds to each class. Hovering over a point shows the class and the name of the shape. Clicking a point or a class in the legend highlights all shapes of its class and dims the others, and clicking the same class again or empty space clears it. The legend can be scrolled with the mouse wheel or by dragging/clicking the scrollbar. The toolbar of matplotlib can be used to zoom and pan (a click while zooming or panning is not a selection). You can run it after `tsne_engine.py`:
```python -m src.step_5.DR.scatterplot -i {path_to_embedding_csv}```
