# tsne_engine.py

```tsne_engine.py``` has the ```DimensionalityReductionEngine``` class that merges and balances the elementary and histogram feature vectors of all shapes in the database, reduces them to 2D coordinates using t-SNE (`sklearn.manifold.TSNE`), and saves the 2D embedding (`file_path`, `shape_class`, `x`, `y`) to a CSV file so ```scatterplot.py``` can render it without recomputing t-SNE.

You can run it from the root directory with:  
```python -m src.step_5.DR.tsne_engine --elementary_csv ./3d_models_final/analysis/4_descriptors/simple_descriptors_normalized.csv --histogram_csv ./3d_models_final/analysis/4_descriptors/histogram_descriptors.csv --perplexity 30 --seed 0 -o ./analysis_output/embeddings/tsne.csv```  
--elementary_csv = Path to the normalized elementary descriptors CSV file.  
--histogram_csv = Path to the histogram descriptors CSV file.  
--perplexity = t-SNE perplexity parameter (default is 30.0).  
--seed = Random seed for reproducible t-SNE embeddings (default is 0).  
--no_balance = If present, runs t-SNE on the raw unscaled feature vectors instead of balancing each descriptor group to unit total variance.  
-o / --output = Output CSV path for the 2D t-SNE coordinates (default is `analysis_output/embeddings/tsne.csv`).

# scatterplot.py

```scatterplot.py``` has the ```Scatterplot``` class that loads the 2D t-SNE embedding CSV from ```tsne_engine.py``` and displays an interactive class-colored 2D scatterplot with a scrollable class legend, hover tooltips showing the shape's class and filename, and click-to-highlight class filtering.

You can run it from the root directory with:  
```python -m src.step_5.DR.scatterplot -i ./analysis_output/embeddings/tsne.csv```  
-i / --input = Path to the 2D embedding CSV file generated by ```tsne_engine.py``` (default is `analysis_output/embeddings/tsne.csv`).  
-s / --save = Optional output file path to save a static PNG image of the scatterplot.  
--no_show = If present, does not open the interactive GUI window (useful when saving an image with `-s`).
