# viewer_example.py

```view_example.py``` uses the ```ModelViewer``` class from ```model_viewer.py``` and actually runs the application  

You can run it from the root directory with:  
```python ./src/step_1/viewer_example.py {3d_shape_path}```  
3d_shape_path = the 3d shape you want to load and render

# model_viewer.py

```model_viewer.py``` has the ```ModelViewer``` class that handles model loading and rendering.
